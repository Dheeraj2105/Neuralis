# Parkinson's Disease Detection System

AI-powered screening tool for early detection of Parkinson's disease using:
- **Motor Control Assessment**: Drawing pattern analysis
- **Clinical Risk Factors**: Demographic and health data evaluation
- **Ensemble Prediction**: Combined ML models (Random Forest + CNN)

## Features
- Interactive drawing canvas for motor assessment
- Comprehensive clinical data form
- Real-time AI analysis
- PDF report generation
- Assessment history tracking

## Technology Stack
- **Frontend**: React + Vite
- **Backend**: Flask + Python
- **ML Models**: scikit-learn, TensorFlow
- **Database**: SQLite

## Medical Disclaimer
This tool is for research and educational purposes only. It is NOT a substitute for professional medical diagnosis. Always consult qualified healthcare professionals.

## Usage
1. Complete motor assessment by drawing patterns
2. Fill clinical information form
3. Get AI-powered risk assessment
4. Download comprehensive PDF report

## Model Performance
- Random Forest Accuracy: ~87%
- CNN Accuracy: ~92%
- Ensemble Accuracy: ~90%
